# ヤングの二重スリット実験

物理の授業向けの3Dシミュレーターです。波面は実験面の中だけに広がり、スクリーン表面で止まります。経路表示では実験面に垂直な方向に波を振動させます。

## 起動

静的HTTPサーバーでフォルダーを配信してください。Pythonが使える場合：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで `http://127.0.0.1:8000` を開きます。ES modulesを使用するため、HTMLのダブルクリックによる `file://` での起動には対応しません。Three.js 0.180.0 と OrbitControls は `vendor/` に同梱してあり、外部CDNへの通信やビルドは不要です。WebGL 2 に対応したブラウザーを使用してください。

## 操作

- 左ドラッグで視点を回転、右ドラッグでパン、ホイールでズームします。画面の「回転」「パン」ボタンで左ドラッグの操作を選べます。
- タッチでは1本指で回転、2本指でズームとパンができます。「パン」を選ぶと1本指でパンできます。
- 「真上」で実験面を上から見られます。「視点を戻す」で斜め上の視点に戻ります。
- 点光源では単スリットを通った波が二重スリットに入ります。単スリットの開口部をドラッグすると、実験面の中で位置を変更できます。「単スリット位置」でも横方向の位置を変えられます。
- レーザーポインターでは単スリットを取り除き、幅のある平行光の平面波を二重スリットに入射させます。「入射角」を変えるとスリットに到達する位相が変わり、干渉縞が移動します。
- 「経路表示」ではスクリーン上の観測位置までの2経路を表示します。白い点のドラッグ、または「観測位置」で到達点を変更できます。
- 「媒質を挿入」で一方の入射経路に直方体の媒質を置きます。屈折率と厚さを変更できます。厚さの上限は媒質が装置の間に収まる値に制限されます。
- 「一時停止」中も視点や実験条件を変更できます。「初期化」は光源、表示、実験条件、観測位置、再生、視点を初期状態に戻します。

## モデル

距離は同じ尺度で計算します。基本値は L = 4、d = 1.3、λ = 0.25 の表示用の単位です。明暗を見やすくするため、実際の実験より波長とスリット間隔を大きく表現しています。起動時には波が装置全体に届いた定常的な状態から表示します。

入射角 θ のレーザーによる2スリット間の入射光路差は d sin θ です。点光源では単スリットから各スリットまでの距離を使います。媒質については各経路と直方体の交差長を求め、媒質内の距離の n 倍を光路長に算入します。この光路長を波面、経路上の振動、スクリーンの干渉縞で共有します。媒質は位相の遅れを説明するモデルとし、境界面での反射・屈折方向や振幅の減衰は扱いません。経路の上下振動は横波の位相を表す模式表示です。

## 確認

```powershell
node --test tests/physics.test.mjs
```

点光源での対称性、レーザー入射角による光路差、媒質の光路長、経路の位相連続性などを検証します。`?debug=1` を付けて起動した場合のみ、読み取り用の `window.youngDiagnostics()` で状態と描画座標を取得できます。

ブラウザー確認は `tests/browser-acceptance.js` に保存しています。ローカルサーバーを起動後、Playwright CLI で `?debug=1` を付けたページを開き、次を実行できます（Chromium用）。

```powershell
New-Item -ItemType Directory -Force output/playwright
npx --yes --package @playwright/cli playwright-cli open "http://127.0.0.1:8000/?debug=1"
npx --yes --package @playwright/cli playwright-cli run-code --filename tests/browser-acceptance.js
```

ローカルChromiumでは、両光源・両表示・媒質、スクリーン位置での波面と経路の終端、マウス操作、タッチを模擬した操作、390/768/1024px幅のレイアウトを確認しています。実機のiPad・Chromebookと公開環境での確認は別途必要です。
